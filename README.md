# TCE-MA Estudos

Portal de estudos desenvolvido para organizar, estruturar e facilitar a preparação para o concurso do Tribunal de Contas do Estado do Maranhão (TCE-MA).

O projeto transforma o conteúdo do edital em uma estrutura organizada de estudo, dividindo cada disciplina em tópicos, subtópicos e desdobramentos obrigatórios, permitindo uma preparação mais objetiva e eficiente.

## Objetivos

- Organizar todo o conteúdo do edital em uma sequência lógica de estudos.
- Detalhar cada tópico em itens menores e mais fáceis de acompanhar.
- Disponibilizar links de apoio para aprofundamento dos conteúdos.
- Facilitar revisões e planejamento de estudos.
- Centralizar em um único lugar todo o conteúdo necessário para o concurso.

## Estrutura

- Conhecimentos Gerais
- Conhecimentos Específicos
- Tópicos detalhados
- Subtópicos obrigatórios
- Links de apoio
- Organização por códigos (LP, INF, RL, DC, DA, etc.)

## Público-alvo

Candidatos ao concurso do Tribunal de Contas do Estado do Maranhão (TCE-MA), especialmente para o Cargo 16 – Técnico Estadual de Controle Externo – Especialidade Técnico-Administrativa.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Aviso

Este projeto possui finalidade exclusivamente educacional e não possui vínculo oficial com o Tribunal de Contas do Estado do Maranhão (TCE-MA) ou com a banca organizadora do concurso.
